# Clase 02 — Interfaz de Usuario (UI)

## Objetivo
Diseñar la interfaz: layouts, paneles, títulos y etiquetas para guiar al usuario.

## Conceptos que se ven
- `titlePanel()`, `sidebarLayout()`, `sidebarPanel()`, `mainPanel()`.
- Organizar contenido con `tabsetPanel()` y `tabPanel()`.
- Etiquetas HTML: `h3()`, `p()`, `tags$strong()`, `tags$hr()`.

## Cómo correr la app
Abrí `app.R` en RStudio y hacé clic en **Run App** (o ejecutá `shiny::runApp()` desde esta carpeta).

## Ejercicio propuesto
Agregá una tercera pestaña con un texto que explique la fuente de datos.
