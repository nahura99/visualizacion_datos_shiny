# Clase 07 — Estética y Navegación

## Objetivo
Mejorar el aspecto visual con bslib y organizar la navegación con pestañas y cards.

## Conceptos que se ven
- `bs_theme()` con la paleta violeta del curso y fuentes de Google.
- `page_navbar()`, `nav_panel()`, `sidebar()`.
- `card()`, `card_header()`, `value_box()` para jerarquizar la información.

## Cómo correr la app
Abrí `app.R` en RStudio y hacé clic en **Run App** (o ejecutá `shiny::runApp()` desde esta carpeta).

## Ejercicio propuesto
Cambiá la paleta de colores y agregá un cuarto value box a elección.
