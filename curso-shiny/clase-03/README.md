# Clase 03 — Entradas de Datos (Inputs)

## Objetivo
Conocer los controles de entrada y entender que cada uno tiene un id que se lee con input$id.

## Conceptos que se ven
- `selectInput()`, `sliderInput()`, `checkboxGroupInput()`, `textInput()`.
- Cada input devuelve un valor; lo inspeccionamos con `verbatimTextOutput()`.
- Todavía no filtramos datos: solo observamos qué devuelve cada control.

## Cómo correr la app
Abrí `app.R` en RStudio y hacé clic en **Run App** (o ejecutá `shiny::runApp()` desde esta carpeta).

## Ejercicio propuesto
Agregá un `dateInput()` y mostrá la fecha elegida.
